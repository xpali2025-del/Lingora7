# Activer Duolingo Super : le guide pas à pas

Pour activer Duolingo Super sans erreur, suivez ces étapes. **Dernière vérification :** 14 octobre 2026, d'après la [page officielle de Duolingo](https://www.duolingo.com/help/use-a-promo-code). Nous revoyons ces étapes tous les 30 jours ou dès que l'interface change.

## Avant de commencer

- Vérifiez que votre compte n'a pas d'abonnement Super actif : selon Duolingo, un code ne peut pas être utilisé sur un abonnement actif.
- Vous devez avoir au moins 13 ans.
- Préparez un navigateur web. D'après Duolingo, l'activation se fait pour l'instant uniquement depuis un navigateur.

## Les étapes d'un code promo Duolingo

1. Ouvrez duolingo.com/redeem dans un navigateur web, sur téléphone, tablette ou ordinateur.
2. Saisissez le code et appuyez sur « Redeem », puis sur « Claim offer » si l'option s'affiche.
3. Connectez-vous à votre compte Duolingo ou créez-en un, puis choisissez le forfait et suivez les écrans jusqu'au démarrage de Super.

## Sur téléphone et tablette

L'activation passe par le navigateur, même sur mobile. Une fois Super démarré, ses avantages apparaissent dans les applications iOS et Android ainsi que sur le web : vous rouvrez simplement l'application comme d'habitude.

## Lien Duolingo Super ne fonctionne pas : erreurs fréquentes

| Ce que vous voyez | Cause probable | Solution |
|---|---|---|
| Promo code invalid | Code expiré, déjà utilisé ou mal saisi | Retapez le code avec soin et vérifiez que vous êtes connecté |
| Le code est refusé | Un abonnement Super est actif, ou moins de 13 ans | Selon Duolingo, le code ne s'applique pas à un abonnement actif |
| Refus alors que vous êtes dans une classe | Compte rattaché à une classe Duolingo | Quittez la classe puis saisissez de nouveau le code |
| Le lien n'est pas arrivé par e-mail | Adresse mal saisie ou message dans les indésirables | Rouvrez votre page de commande pour corriger l'adresse, ou écrivez-nous avec le numéro de commande |

## Questions fréquentes

**L'abonnement se renouvelle-t-il automatiquement ?**
Selon Duolingo, tous les abonnements se renouvellent automatiquement tant qu'ils ne sont pas annulés.

**Ma progression sera-t-elle affectée ?**
Selon Duolingo, votre progression et votre série ne sont pas touchées quand un abonnement commence ou se termine.

**Que faire si le lien ne fonctionne pas ?**
Écrivez-nous avec votre numéro de commande. Pour l'aide officielle : [duolingo.com/help](https://www.duolingo.com/help). Pas encore de lien ? Consultez la page [abonnement Duolingo Super](/fr/).
